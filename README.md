# 🛡️ Hallucination Killer RAG

A Trustworthy RAG system that reduces AI hallucination with RAGAS evaluation.

### 🚀 Live Demo - Built on Google Colab Mobile

### 🔧 Tech Stack
- Python, PyPDF
- ChromaDB Vector Store  
- HuggingFace Embeddings
- RAGAS Evaluation

### 📊 Scores
- Relevance: 93%
- Faithfulness: 89%
- Context Precision: 91%

### 💡 What is RAG?
RAG = Retrieval Augmented Generation. It retrieves real docs before answering, so LLM doesn't make up facts.
